# PlotPoint — Texas 2026 Required-Reading Lists (public-domain build plan)

Captured 2026-08-01 from the user's list of the **Texas literary works lists adopted in
2026**.

> **Timeline / framing note (put this on any hub page that references these):** these
> statewide lists were **adopted in 2026** but are scheduled for implementation **no
> earlier than the 2030–2031 school year**. They are **not** requirements for 2026–2027.
> PlotPoint builds them ahead of time as an optional, aligned resource — not as a claim
> that they are currently mandated.

This file is the durable roadmap. It complements `SHORT_STORIES_PLAN.md` (short-story
backlog) and `correlations/` (TEKS/ELPS/UDL alignment). Nothing here is built unless the
"Already live" table says so.

Copyright rule of thumb (US, **as of 2026**): **published 1930 or earlier → public domain.**
⚠️ This cutoff **advances one year every January 1** (1931 → PD in 2027, and so on), so by the
2030–31 implementation window it will read "**1934 or earlier**." Re-derive it from the
current year (year − 96) before making a PD call, rather than trusting the frozen "1930."
Every title below is PD in the US on its listed basis; federal speeches/orders are PD as U.S.
government works regardless of date (Gettysburg, General Order 108, JFK/FDR addresses).
The only friction is **named copyrighted translations** — see section E.

## D. How to adapt the room engine per type

The standard room (`window.__ROOM__.content` — hook, goals, stages, ace, vocab[9],
relic[7 artifacts], ctob[6 locks], arcade[8 cards], analysis, extend, genaiPrompts[6],
teacher, standards) assumes a narrative. Adaptations:

- **D1. Poems.** Keep all 10 sections but re-cast: `stages` → stanza/movement walkthrough;
  `arcade` buckets → device ID (imagery / meter / rhyme / figurative language); `relic`
  artifacts → key images or lines *(paraphrased — never reproduce the poem in full)*;
  analysis MCQs on theme, tone, structure. Because poems are short, **verify every fact
  against the PD text but reproduce only brief, fair-use phrases**, staying with house
  paraphrase style. Poems are the fastest batch — good momentum builders.
- **D2. Scripture / sacred poetry.** Build with a strictly **literary/academic frame**
  (imagery, parallelism, structure, historical-literary context, influence on English
  prose) and **neutral, non-devotional** tone — consistent with how Texas lists them as
  literary works. KJV & JPS-1917 are PD, so quotation is legally safe, but keep house
  paraphrase style and add a short "studied here as literature" note in `meta`. Flag for
  content review before publishing.
- **D3. Speeches / federal documents.** Full PD (U.S. gov't works). `stages` → rhetorical
  moves; `arcade` → ethos/pathos/logos or claim/evidence/warrant; analysis → rhetorical
  purpose & historical context. No `gutenberg`/`audio` fields unless a clean source exists
  (many are on Gutenberg / Avalon / gov archives — link where clean).
- **D4. Long works (novels/plays/nonfiction).** Same as existing novel rooms
  (`butterflies`, `dracula`, etc.). For **Walden, Democracy in America, Franklin
  Autobiography, Divine Comedy** — scope each room to the **named selection/part**, not the
  whole work, and say so in `meta`.

## E. Copyright caveat — public-domain works with a *named copyrighted translation/version*

The underlying work being ancient/PD does **not** make every English *translation* PD — a
modern translation carries its own copyright. Rule: **build the room on a public-domain
translation** (all the ones below are on Project Gutenberg), paraphrase in house style, and
link only the PD text. If a district assigns a *specific* modern translation, that's a
licensing matter for the district — the room still teaches the work from the PD edition and
notes the substitution in `meta`.

**Handling:** No. 78 (Hamilton, 1788) is public domain. When English III long-work capacity
frees up, build it as its **own short document room** in the §B2 speeches/documents mold

existing `federalist` room. Until then it is a **known, intentional gap**, not an oversight.
The `federalist` room's own scope note already limits it to Nos. 10 and 51, so nothing there
overclaims.
