# PlotPoint — Short Stories Plan (backlog & copyright guidance)

Captured 2026-07-31 from user suggestions. This file is the durable to-do list for
adding short-story rooms to PlotPoint. Nothing here is built yet unless noted.

Two build modes (same as the novels):
- **Public-domain (PD) story → full room.** Include the free **Read & Listen** panel
  (Project Gutenberg / American Literature / LibriVox text + audio links). Safe to link
  and to reproduce quotations if ever needed — but PlotPoint rooms still paraphrase by
  house style.
- **Copyrighted story → Kindred-style companion.** Reproduce **no text**, invent no
  quotations, add the per-work CC BY 4.0 disclaimer, `rights:"Copyrighted"`, no
  text/audio links, and a content-review note. Verify facts against a lawful copy the
  user supplies (kept only in `copyrighted_texts_do_not_upload/`, never committed).

## Copyright rule of thumb (US, as of 2026)
- **Published 1930 or earlier → public domain** in the US (95 years; 1930 + 95 → PD on
  Jan 1, 2026). So authors like Poe, O. Henry, Maupassant, Chopin, Stockton, London,
  Saki, Bierce, W. W. Jacobs, Gilman, and Connell's *The Most Dangerous Game* (1924) are
  safe as full rooms.
- **Published 1931 or later → treat as copyrighted** unless clearly proven otherwise
  (e.g., Brave New World 1932 is still under copyright until 2028). When unsure, use the
  companion mode.
- The curated sites the user shared (classicshorts.com, americanliterature.com,
  libraryofshortstories.com) host mostly **public-domain** classics — good sourcing for
  PD full rooms — but always confirm the individual story's date/author before building.
