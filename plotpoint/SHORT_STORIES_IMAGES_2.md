New public-domain short-story rooms (grown from `SHORT_STORIES_PLAN.md` after its
named PD backlog was fully built): **The Storyteller** (Saki), **The Boarded
Window** (Bierce), **A Pair of Silk Stockings** (Chopin), **The Lottery Ticket**
(Chekhov). Each room needs **1 hero + 7 relic artifacts = 8 images**. Drop each
generated file into that room's `images/` folder using the **exact filename**
shown (the room data already references these paths); pages render labeled
placeholders until the assets land.

**Spec:** square **1024×1024 WebP**, instructional-illustration style (an
educational, storybook-realistic look — not a photo, not a copyrighted edition's
artwork), warm and legible, **no legible text in the image**. Keep a consistent
palette per room (noted below).
