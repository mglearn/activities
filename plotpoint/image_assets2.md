# PlotPoint — Image Assets Needed, Part 2

Continuation of [`image-assets-needed.md`](image-assets-needed.md). Part 1 covered the
hub hero and **The Metamorphosis** relic artifacts. This file covers **every room
built since**, plus **proposed CLT-canon titles** not yet built.

**Rules (unchanged from Part 1)**
- No text, logos, watermarks, or signatures in the image; the UI supplies all words.
- Never reproduce a real book cover, film still, published illustration, or a named real
  person's likeness. Relic artifacts are **instructional reconstructions** — generic,
  period-appropriate objects and scenes.
- Neutral, uncluttered backgrounds; soft editorial / "museum" lighting.
- Every image is **optional**: pages render a labeled placeholder if a file is missing.
- Save optimized PNG/WebP at the size given, inside that room's `images/` folder.

**Relic still-life style spec** (append to any single-object prompt below):
> Photorealistic museum still-life of a single object, centered, on a soft neutral
> gray-taupe seamless background. Even, soft studio lighting, subtle shadow beneath,
> shallow depth of field. Period- and place-appropriate. Real and tactile — an
> instructional reconstruction, not an illustration. Square-ish 4:5 framing. No text,
> no labels, no people (unless the item calls for a figure), no book cover.

**Sizes:** relic artifacts **1024 × 1280** (4:5). Optional room heroes **1600 × 720**.

Legend: 🟢 = live room, image referenced today · ⚪ = proposed room, not yet built.

## Generation & optimization notes
- Generate at the stated size (or larger, then downscale); optimize with `oxipng`/Squoosh.
- After export, confirm each image's `alt` text in the room's `data.en.js`
  (`content.relic.artifacts[].alt`, where present) matches the final picture.
- Keep every room's images inside that room's `images/` folder so rooms stay
  self-contained and fully offline-capable.
