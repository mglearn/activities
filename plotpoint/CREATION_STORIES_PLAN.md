# PlotPoint — Creation Stories (comparative cosmogony enrichment plan)

Captured 2026-08-07. A **comparative world-mythology** enrichment cluster: how different
cultures explain origins through story. This is **not** a Texas 2026 required-reading item —
it's general-catalog enrichment that extends the existing `myths` (Bulfinch), `eden`
(Genesis 2–3), and scripture rooms.

> **Framing note (put a version of this on any hub page that references these):** these rooms
> study creation stories **as literature** — narrative, archetype, symbol, structure, and
> cultural context — not as science and not as competing truth claims. The question is *how a
> culture uses story to explain where everything came from*, never *which account is true*.
> Neutral, non-devotional, comparative. Each room carries a content-review note.

Nothing here is built unless a "Status" column says so. Complements `SHORT_STORIES_PLAN.md`,
`TEXAS_2026_PLAN.md`, and `correlations/`.

---

## A. Viability — why this fits PlotPoint

- **Already half-started.** `eden` (Adam and Eve, Genesis 2–3) is typed "Origin narrative ·
  Myth & symbol"; `myths` covers Greek/Roman; the scripture rooms prove the neutral literary
  frame works. Creation stories are a natural extension, not a new departure.
- **Best possible ACE showcase.** *Connect* and *Extend* ARE cross-cultural comparison —
  comparing how cultures answer the same question is the signature payoff creation stories
  offer that few other texts can.
- **Engine fit is ideal.** These are short-to-medium narrative/poetic texts — same profile as
  the poem/scripture/short-story batches the 10-section engine already handles.
- **Strong world-lit / TEKS alignment** (archetype, cultural & historical context, comparative
  literature, allusion, author's craft, theme).
- **Good public-domain availability** for the classical/literary corpus (see §C).

## B. Guardrails (the crux of viability — read before building)

1. **Neutral literary/comparative frame** — reuse the scripture pattern (`TEXAS_2026_PLAN` §D2):
   imagery, structure, parallelism, archetype, influence; "studied here as literature" note in
   `meta`; non-devotional tone; no "which is true" framing anywhere.
2. **Texas optics** — "creation stories" can be misread as the evolution/creationism flashpoint.
   Frame explicitly as **comparative world mythology / how cultures explain origins**, with a
   per-room content-review note. Not science, not apologetics, not critique of any faith.
3. **Indigenous / oral sacred traditions — HOLD by default.** Many Native American and
   Aboriginal creation stories are sacred, sometimes ceremonially/seasonally restricted, and
   the public-domain sources are colonial ethnography (often inaccurate, no community consent).
   **Do not** treat Budge/Brasseur-era texts as authoritative. Build these ONLY with
   community-vetted sources and cultural review; otherwise omit. This is where viability drops.
4. **Translation copyright** — same rule as `TEXAS_2026_PLAN` §E: build on a public-domain
   translation (all listed below are pre-1930 / Gutenberg), paraphrase in house style, link
   only the PD text; if a named modern translation is required, that's a district licensing
   matter. Living religions (Judaism, Christianity, Hinduism) → neutral, non-devotional note.

## D. Signature feature — the comparative capstone

Build **"How the World Began: A Comparative Cosmogony"** as a capstone room (and/or a themed
cluster with a `creation`/`mythology` facet), around a **new arcade mechanic that isn't a
reskin**: sort creation motifs by archetype —
- **chaos → order** (Theogony, Ovid)
- **cosmic egg** (Pangu)
- **world from a body** (Ymir, Tiamat)
- **divine word / ex nihilo** (Genesis 1)
- **the unknowable origin** (Nasadiya Sukta)
- **emergence / earth-diver** (many traditions — build only with vetted sources)

The *Extend* task writes itself: "identify the archetype, then compose your own origin story
using it," or "compare two cultures' answers — what transfers, what changes, where the
comparison breaks." Relic Room = cosmological artifacts (primordial waters, world tree, cosmic
egg, the Enuma Elish tablet, maize, the seven-day structure).

## E. Engine adaptation per type

Mostly reuse existing patterns — no new engine work:
- **Short narrative myths** (Enuma Elish, Pangu, Theogony) → the standard 10-section room, like
  the short-story rooms; relic artifacts = cosmological objects; arcade = archetype/motif sort.
- **Scripture/sacred poetry** (Genesis 1, Nasadiya Sukta) → the §D2 scripture pattern: literary
  frame, "studied as literature" `meta` note, content-review flag, KJV/Griffith PD text.
- **Comparative capstone** → standard room whose `arcade` is the archetype sort and whose
  `analysis`/`extend` are explicitly cross-text. May reference the sibling rooms.

## F. Recommended sequencing

1. **Pilot (4) + capstone:** Genesis 1 (KJV), Enuma Elish, Norse Völuspá, Rig Veda 10.129 —
   geographic + tonal range, complements `eden`/`myths`, avoids both the Indigenous-sourcing and
   creationism-optics traps — then the "How the World Began" capstone.
2. **Expand (candidates):** Theogony, Pangu & Nüwa, Ovid I, Prometheus & Pandora.
3. **Build-with-care:** Popol Vuh, Egyptian — PD-translation-only + cultural/scholarship review.
4. **Hold:** Indigenous N. American / Aboriginal traditions until community-vetted sources exist.

Each room follows the standard pipeline (verify facts, no reproduced passages beyond fair PD
quotation in house style → jsdom/structural test → 6 translation packs → parity → `titles.js`
card with a `creation`/`mythology` genre tag → deploy → poll → image doc).
