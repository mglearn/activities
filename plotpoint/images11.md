# PlotPoint — Image prompts for the 5 Texas-2026 short-story rooms (Phase 2a)

40 images: **5 heroes** (square, 1024×1024) + **35 relic artifacts** (portrait 4:5, 1024×1280).
Export **WebP**. Paths exact — drop each at `plotpoint/<room>/images/<file>`.

## Style rules
Warm, painterly, muted palette; soft directional light; shallow depth of field. **No real
faces / no photoreal identifiable people** — symbolic objects, silhouettes, hands,
landscapes, period detail. Clearly an **instructional reconstruction / concept
illustration**, not artwork from any edition. Each room's accent tints the light.

---
