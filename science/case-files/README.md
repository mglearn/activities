# CER & ACE Case Files

Five hands-on science cases for grades 5–8, each a Page 1 investigation plus
your choice of a Page 2 response — Claim–Evidence–Reasoning or
Articulate–Connect–Extend. Published at
**https://mglearn.github.io/activities/science/case-files/**.

## What ships

| File in `files/` | What it is |
|---|---|
| `CER_ACE_Case_Files_Teacher_Guide.pdf` | 9 pp — prep, keys, circulating questions, misconceptions, standards map, K–16 ladder |
| `CER_Case_Files_Student_Packet.pdf` | 14 pp — the five cases with a CER Page 2, worked example up front |
| `ACE_Case_Files_Student_Packet.pdf` | 14 pp — same investigations with an ACE Page 2 |
| `CER_ACE_Case_Files_Editable_Packets.pptx` | 28 slides, Letter portrait — the packets as real text boxes and tables |
| `CER_ACE_Case_Files_Projection_Deck.pptx` | 20 slides, 16:9 — for the board rather than the printer |

## Design system

"Case-file dossier": warm paper, oxblood case stamps, typewriter field labels,
ruled evidence logs. Oxblood carries CER, indigo carries ACE, so the two student
packets are tellable apart in a stack of copies.

- **Zilla Slab** — display, case titles, section heads
- **IBM Plex Mono** — labels, stamps, case numbers, folios
- **Source Sans 3** — body and table copy

Colors are oklch-derived and written as hex in three places that must stay in
step: `src/print.css` (`:root`), `src/build-decks.js` (`K`), and the `:root`
block inside `src/build-site.js`.

The PowerPoint decks substitute **Georgia / Consolas / Calibri** — PowerPoint
cannot fall back through a font stack the way the PDFs and the site can, so the
decks use faces that ship with Office and Google Slides.

## Building

`src/content.js` is the single source of truth. Every output is generated from
it; nothing is hand-edited downstream.

```
node src/build.js          # → files/*.pdf   (headless Chrome, selectable text)
node src/build-site.js     # → index.html
node src/build-decks.js    # → files/*.pptx  (needs pptxgenjs, see below)
node src/build-canvas.js <dir>   # → .dc.html artboards for a design canvas
```

`build.js` and `build-canvas.js` share `src/page-parts.js`, so a layout change
lands in the PDFs and the canvas at once. Intermediate HTML goes to
`src/.work/` — a dot-directory, which the hub search index deliberately skips.

**pptxgenjs is not vendored.** `/media/mg/data` rejects the symlinks npm wants,
so install it elsewhere and point `NODE_PATH` at it:

```
npm install pptxgenjs --prefix /tmp/sdc
NODE_PATH=/tmp/sdc/node_modules node src/build-decks.js
```

`src/fonts/` holds the three webfont families as TTFs so the PDF build embeds
them without a network round-trip. The website and the design canvas load the
same families from Google Fonts.

  Detectives breakout landing

This area is a single landing page plus downloads, and `build-search-index.js`
skips landing pages by design — so, like `gtky/` and `sojourn/`, it carries
hand-written `data-kw` on the hub card instead of a harvested search entry.
**Re-run `node ../../build-search-index.js` and update the hub tally** after any
change that adds or removes a card.

## On the name

The parent folder `../` is a legacy redirect stub pointing at
`../../ctobs/science/`, which is a *different* activity called **Science
Detectives** (99 K–8 online breakouts). These packets were renamed from "Science
Detective Cases" to **CER & ACE Case Files** to end that collision; the two are
cross-linked as the hands-on and digital halves of the same idea.

The routine inside the packets is "The Case File Routine" and the callout is the
"Evidence rule" — both were renamed away from "detective" for the same reason.
The blog post keeps its own title, and Case 03 is still called "State
Detectives" because that is the case's name.

## Provenance

The five case photographs and the cover photograph came from the previous
edition of this packet. `assets/hero.jpg` is cropped to drop that edition's
title, which was baked into the left third of the image.

The previous edition — `blog_entry.docx` and four `Science_Detectives_*` files —
was moved out to `/media/mg/data/mystery/`. It is not in this repo.

## What is not committed

`src/.work/` — the intermediate HTML the PDF build hands to headless Chrome.
Regenerated by `node src/build.js`; ignored via `.gitignore`.

`src/fonts/` **is** committed (2.4 MB of TTFs). The PDF build embeds these
locally so a rebuild is reproducible offline and does not depend on Google
Fonts being reachable.
