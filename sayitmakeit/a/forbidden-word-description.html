Forbidden-Word Description

GradesK–8
STEAM🎨 Arts & Design
Materials Vocabulary cards with prohibited clue words.

What to describe

The Describer must convey a STEAM term (like “parallel,” “circuit,” or “symmetry”) without saying the word itself, using only defining attributes, so the Builder identifies or builds it.

Roles

How a round works

Make it harder or easier

Harder

Describe using only shape, position, and color words — no gestures, no questions.

Easier

Allow yes/no questions and agree on a shared starting shape or anchor point.
