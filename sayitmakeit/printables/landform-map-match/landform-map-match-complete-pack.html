Landform Map Match

Classroom-ready printable pack · Grades 3–8

Pack contents
Blank maps, landform symbols, challenges, and a reference guide. Two student sets are included.

Teacher directions

  1. Orient both maps north-up.
  2. The Describer places land and water features.
  3. Use relative and cardinal directions.
  4. Check that connected features make geographic sense.

Before class

  • Print at 100% on US Letter paper. Use cardstock or laminate for reuse.
  • Cut on the thick solid borders. Keep Set A and Set B separate.
  • Give challenge/model cards only to the Describer.
  • Use a folder, book, or tabletop barrier so partners cannot see each other’s work.

Accessibility and accommodations

Begin with mountain, river, lake, plain, and island. Use the definition strip.

Landform Map Match reference

Landform key

Mountain: high, steep land. Valley: low area between higher land. Plain: broad, relatively flat land. Plateau: elevated flat area. Peninsula: water on three sides. Island: water on all sides. Rivers flow downhill.

Quality check after a round

  • Can each student identify pieces by shape or label without relying on color?
  • Do both models match in pieces, order, orientation, and relative position?
  • Which direction was most precise? Which should be revised?
