Cup Coordinate Build

Classroom-ready printable pack · Grades K–8

Pack contents
Coordinate mats, orientation keys, cup tokens, and challenge cards. Two student sets are included.

Teacher directions

  1. Align both mats with START nearest the students.
  2. The Describer places cups by column, row, and stack level.
  3. The Builder recreates the arrangement behind a barrier.
  4. Compare from the shared START edge and revise ambiguous coordinates.

Before class

  • Print at 100% on US Letter paper. Use cardstock or laminate for reuse.
  • Cut on the thick solid borders. Keep Set A and Set B separate.
  • Give challenge/model cards only to the Describer.
  • Use a folder, book, or tabletop barrier so partners cannot see each other’s work.

Accessibility and accommodations

Begin on a 3 × 3 mat with one level. Tokens differ by number and pattern, not color alone.

Cup Coordinate Build reference

Orientation key

Name column first, then row (for example, 2-B). Keep START nearest each student and north pointing away. For stacks, name levels from bottom to top.

Quality check after a round

  • Can each student identify pieces by shape or label without relying on color?
  • Do both models match in pieces, order, orientation, and relative position?
  • Which direction was most precise? Which should be revised?
