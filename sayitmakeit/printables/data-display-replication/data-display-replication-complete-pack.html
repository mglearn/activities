Data-Display Replication

Classroom-ready printable pack · Grades 3–8

Pack contents
Blank graph templates, display/data cards, challenges, and answer keys. Two student sets are included.

Teacher directions

  1. Give partners the same blank template.
  2. The Describer chooses a completed data display.
  3. Explain title, labels, scale, categories, and values.
  4. Compare structure before individual marks.

Before class

  • Print at 100% on US Letter paper. Use cardstock or laminate for reuse.
  • Cut on the thick solid borders. Keep Set A and Set B separate.
  • Give challenge/model cards only to the Describer.
  • Use a folder, book, or tabletop barrier so partners cannot see each other’s work.

Accessibility and accommodations

Begin with a four-category bar graph and scale of one. Use the feature checklist.

Data-Display Replication reference

Display checklist

Include an accurate title, labels, consistent scale, and values. Pictographs need a key. Line graphs show ordered change, often over time; line plots show frequency above a number line. Never imply an unmarked broken axis.

Quality check after a round

  • Can each student identify pieces by shape or label without relying on color?
  • Do both models match in pieces, order, orientation, and relative position?
  • Which direction was most precise? Which should be revised?
