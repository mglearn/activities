Coordinate-Plane Journey

Classroom-ready printable pack · Grades 5–8

Pack contents
First- and four-quadrant mats, point/path tokens, challenges, and keys. Two student sets are included.

Teacher directions

  1. Choose the same plane and identify the origin.
  2. The Describer states ordered pairs in sequence.
  3. The Builder plots and connects the points.
  4. Compare coordinates before the finished path.

Before class

  • Print at 100% on US Letter paper. Use cardstock or laminate for reuse.
  • Cut on the thick solid borders. Keep Set A and Set B separate.
  • Give challenge/model cards only to the Describer.
  • Use a folder, book, or tabletop barrier so partners cannot see each other’s work.

Accessibility and accommodations

Start in quadrant I. Use x first, then y and trace from the origin.

Coordinate-Plane Journey reference

Coordinate key

Ordered pairs are (x, y): move horizontally for x, then vertically for y. An axis point has one coordinate equal to zero. Sample rectangle: (−4,−2), (4,−2), (4,2), (−4,2).

Quality check after a round

  • Can each student identify pieces by shape or label without relying on color?
  • Do both models match in pieces, order, orientation, and relative position?
  • Which direction was most precise? Which should be revised?
