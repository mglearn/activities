Cardinal-Direction Builder

Classroom-ready printable pack · Grades K–8

Pack contents
Compass mats, landmarks, direction tokens, and challenges. Two student sets are included.

Teacher directions

  1. Align both mats north-up.
  2. The Describer places a center and landmarks.
  3. State direction and distance for each landmark.
  4. Compare from the common center.

Before class

  • Print at 100% on US Letter paper. Use cardstock or laminate for reuse.
  • Cut on the thick solid borders. Keep Set A and Set B separate.
  • Give challenge/model cards only to the Describer.
  • Use a folder, book, or tabletop barrier so partners cannot see each other’s work.

Accessibility and accommodations

Start with N, E, S, W at one distance. Add intermediate directions later.

Say It, Make It · Activity 55Answer key / teacher reference

Cardinal-Direction Builder reference

Compass key

Clockwise: N, NE, E, SE, S, SW, W, NW. Opposites: N/S, E/W, NE/SW, NW/SE. Rings count outward from center.

Quality check after a round

  • Can each student identify pieces by shape or label without relying on color?
  • Do both models match in pieces, order, orientation, and relative position?
  • Which direction was most precise? Which should be revised?
