# Image Prompts — TCEA Curiosity Challenge (October packs)

## How to use this file
1. Copy an image's prompt below into your image generator.
2. The site serves **WebP** (much smaller than PNG). Generate the image, then convert it to
   WebP at the exact path in its **Save to** line (paths are relative to this `curiosity/`
   folder), keeping the same filename so the pages find it:
   ```
   cwebp -q 82 your-image.png -o <Save to path>
   ```
3. Commit and `git push origin main` from the `activities/` repo — GitHub Pages
   redeploys `mglearn.github.io/activities/` automatically. No code changes needed.

The full disk path is `~/Documents/vibecoding/mglearn/activities/curiosity/<Save to path>`.
If a file is ever missing, the activity falls back to "🖼️ Image coming soon — use the text
description," so the packs stay usable regardless.

**Global rules for every image (from the series visual standard):**
- **No text, letters, numbers, or lettering of any kind** in the image.
- Classroom-appropriate; any human figures fully clothed (prefer abstract/silhouette or none).
- No distorted logos, no fake medals, no copied sacred or personal imagery.
- Accurate alt text is provided — keep it with the file.

Priority: **★ Functional** images appear inside an activity. **◆ Feature** images are optional
polish (social/OG cards, print covers); the landing pages work without them.
