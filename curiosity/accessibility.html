TCEA Curiosity Challenge

Accessibility

These activities are designed so every student can take part — with a keyboard, with a screen reader, on a phone, or on paper.

Built in to every challenge

  • Keyboard first. Every control is a real button or form field you can reach with Tab and activate with Enter or Space. There is a visible focus outline.
  • No drag-only interactions. The sorting challenges work by selecting a card and then choosing a category button — there is no drag-and-drop you must use. Ordering challenges use Up/Down buttons.
  • Color is never the only signal. Correct and incorrect placements are marked with a ✓ or ✗ and a written explanation, not color alone.
  • Text for every image. Informative images have alt text, and the visual challenges include a full written description you can expand and read instead of the picture.
  • Data described in words. Tables and evidence sets include a plain-language description.
  • Reduced motion. Animations and smooth scrolling are turned off automatically when a device requests reduced motion.
  • Responsive layout. The pages reflow to a single column on small screens with no horizontal scrolling.
  • Live feedback. Results are announced to screen readers through polite live regions.

Sorting without a mouse

  1. Tab to a card in the bank and press Enter to select it.
  2. Tab to the category where it belongs and press Enter to place it.
  3. You will hear (and see) whether it was a good fit, with a short explanation.
  4. Use the × on a placed card to send it back to the bank.

A paper option for everyone

Every pack has a printable student version that needs no device at all — useful for low-bandwidth classrooms, students who work better on paper, or as a no-screen accommodation.

Tell us what to improve

If any challenge is hard to use with assistive technology, that is a bug we want to fix. Please report it through your TCEA contact so we can improve the shared engine for every pack at once.
