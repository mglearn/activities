Privacy

Plain language, no hedging.

What this site collects

Nothing. There is no account, no login, no name field, no student ID field, and nowhere for a student response to be submitted. Student thinking happens on paper or out loud.

What runs in the browser

  • The pages load four JSON data files from this same site to build the activity cards and word-part cards.
  • Filter choices on the activity page are written into the web address so a link can be shared. Only filter names and search terms you type go there — never a student response.
  • No cookies are set. No localStorage is used. Nothing persists between visits.
  • No analytics, no advertising trackers, no third-party scripts, no external fonts, no content delivery networks.

Printables

Handouts are static HTML. They print from the browser. Nothing is uploaded, and no print service is involved.

Teacher keys

Answer keys are separate pages, stored in a separate folder, and are never embedded in a student handout. On static hosting that is organization, not security — anyone who knows the address can open a key. The project does not pretend otherwise. If you need keys that students genuinely cannot reach, host them somewhere with authentication.

Offline use

Download the folder and the site works from a local drive. Nothing here needs the internet after that.
